# Solidity GUI

Solidity GUI provides an interface to build geometries, and create the materials and conditions necessary to run the [Solidity](https://solidityproject.com/) solver.

## Documentation

Full documentation documentation is available [on GitHub pages](https://ImperialCollegeLondon.github.io/Solidity-GUI/).

## Quickstart

1. Install dependencies:

   ```sh
   pip install -r dev-requirements.txt
   ```

2. Run the GUI:

   ```sh
   python -m solidity_gui
   ```

For detailed setup, troubleshooting, and developer notes, see [docs/getting_started.md](docs/getting_started.md).
