    config

    solidity_gui.config ¤

    Configuration settings for the program.

    Attributes¤

    APP_AUTHOR = 'Imperial College London' module-attribute ¤

    The author of the app.

    APP_NAME = 'Solidity GUI' module-attribute ¤

    The name of the app.

    BACKGROUND_COLOUR = (0.1, 0.2, 0.4) module-attribute ¤

    Background colour of vtk display window.

    CENTRAL_LAYOUT_SPACING = 20 module-attribute ¤

    Spacing between elements in central layout.

    COMMAND_BOX_MAXIMUM_HEIGHT = 100 module-attribute ¤

    Maximum height of the command box.

    DEFAULT_ORIENTATION_VECTOR = (1, 0, 0) module-attribute ¤

    Default camera orientation.

    DEFAULT_UP_VECTOR = (0, 1, 0) module-attribute ¤

    Default up direction for camera.

    DOCKER_IMAGE_ID = 'a499e398855f0897048477a5efbc54ee2f217626c330ca0495b8909433e4ab11' module-attribute ¤

    The content-addressable image ID for the Docker image. This is different from the image digest above. To check what the image ID is, use the get_docker_image_id.py script.

    DOCKER_IMAGE_ID_SHORT = DOCKER_IMAGE_ID[:12] module-attribute ¤

    A shorter, more human-readable version of the image ID.

    MESH_COLOUR = (1, 1, 1, 1) module-attribute ¤

    Colour of rendered mesh components (RGBA format).

    MESH_SELECTION_COLOUR = (1, 0, 0, 1) module-attribute ¤

    Colour of selected mesh components (RGBA format).

    SOLIDITY_CONTAINER_NAME = 'solidity' module-attribute ¤

    The name to use for the Docker container running Solidity.

    SOLIDITY_DOCKER_IMAGE = f'ghcr.io/imperialcollegelondon/solidity_project_dev@sha256:{_DOCKER_IMAGE_DIGEST}' module-attribute ¤

    The path to the Docker image to run.

    SOLIDITY_LAYOUT_FILE_NAME = 'layout.txt' module-attribute ¤

    Solidity layout file name, which provides format for elements and particles.

    SOLIDITY_MATERIALS_FILE_NAME = 'mat.txt' module-attribute ¤

    Solidity materials file name.

    SOLIDITY_MAT_FILE_NAME = 'mat.txt' module-attribute ¤

    Solidity mat file name.

    SOLIDITY_MAT_TEMPLATE_FILE = 'mat.txt.jinja' module-attribute ¤

    Solidity mat.txt template file.

    SOLIDITY_PELLET_FILE_NAME = 'pellet.txt' module-attribute ¤

    Solidity file name for elements and particles file.

    SOLIDITY_Y3D_FILE_NAME = 'BST.Y3D' module-attribute ¤

    Solidity Y3D file name.

    SOLIDITY_Y3D_TEMPLATE_FILE = 'BST.Y3D.jinja' module-attribute ¤

    Solidity Y3D template file.

    TOOLBAR_ICON_SIZE = (16, 16) module-attribute ¤

    Size of icons in toolbar (width, height).

    TREE_VIEW_WIDTH = 200 module-attribute ¤

    Width of Tree View on left-hand side.

    TRIAL_EXPIRY_DATE: date | None = None module-attribute ¤

    The expiry date for the program if it's a trial version.
