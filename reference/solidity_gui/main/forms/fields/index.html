    fields

    solidity_gui.main.forms.fields ¤

    Submodule related to individual form fields.

    Fields are used to build up forms and represent semantically distinct items of data. This is entirely analogous to fields used in libraries such as Marshmallow, WTForms or Django Forms. Fields are intended only to be used as attributes of Form classes.

    For our purposes, a Field class ties together a Marshmallow field class and a Widget class with additional data for display to the user. The Marshmallow class of a Field effectively defines the underlying datatype and is used by a Form instance to construct a Marshmallow Schema for data validation. Validator functions may also be provided to a Field and these are passed to the Marshmallow field when the Schema is constructed.

    The Widget class specified for a Field represents the actual GUI component that should be presented to the user. All usable Field classes provide a default Widget class however the Widget class may also be provided at initialisation time.

    description: str | None = None,
    validators: Iterable[Callable] = [],
    widget: Widget | None = None,
    field_validators: list[Callable] = [],

    """Initialise a new instance.

    Args:
      length: number of values represented by the field
      display_name: human friendly name
      description: human friendly description of the field's purpose
      validators: marshmallow compatible functions to validate individual values
      widget: the GUI widget displayed to the user
      field_validators: marshmallow compatible functions to validate the full field
    """
    self.display_name = display_name
    self.description = description
    self.validators = validators
    self.widget = widget if widget else self._default_widget
    self.length = length
    self.field_validators = field_validators

    def field_info(
    self,
    name: str,
    data: DataType | list[DataType] | None,
    errors: dict[int, list[str]] = {},
) -> FieldInfo:
    """Return a FieldInfo object for this Field.

    Args:
      name: the name of the field
      data: data for pre-population of inputs
      errors: error messages for individual inputs
    """
    header = self.display_name if self.display_name else name
    if data:
        if isinstance(data, list):
            if len(data) != self.length:
                raise ValueError("Number of data items must match Field length.")
            inputs = [self.input(d) for d in data]
        else:
            if self.length != 1:
                raise ValueError("Expected a list of data items.")
            inputs = [self.input(data)]
    else:
        inputs = [self.input() for _ in range(self.length)]
    if len(inputs) != self.length:
        raise ValueError("Number of values provided by `data` is incorrect.")

    return FieldInfo(
        input=inputs,
        errors=errors,
        header=header,
        description=self.description,
    )
