    GmshDaemon(name) ¤

    Child process logic for forwarding calls to a GeometryWrapper instance.

    This class works closely with the GmshProcess class that handles the parent process logic for function call forwarding. Separation into separate classes minimises the datastructures that need to be passed to the child process and avoids serialisation issues on certain platforms.

    GmshListener(queue) ¤

    Bases: QThread

    A class to listen for generated meshes produced in the separate gmsh process.

    We use a separate thread so that the main thread isn't blocked waiting for meshes to be received. Qt's signal/slot mechanism is used to pass this mesh back to the main thread, which invokes PyPubsub's sendMessage() function. This needs to be run on the main thread in case listeners want to modify the GUI (all GUI operations have to be on the main thread).

    GmshProcess(mesh_name) ¤

    A class for communicating with gmsh on a separate process.

    Using the gmsh module seemingly only works on the main thread of the Python process, so in order to be able to run gmsh operations in the background, it is necessary to spin up a separate process for this.

    This class acts as an intermediate layer passing function calls to a GmshDaemon instance. Function calls may be run either synchronously or asynchronously, in which case the return value is injected into the GUI main loop (via a Pyside Signal on GmshListener) and broadcast using a pubsub message.

    def call_function(self, function_name: str, **kwargs: Any) -> object:
    """Call a GmshWrapper method and await the result.

    Args:
      function_name: name of the method to call
      kwargs: keyword arguments to pass into the method
    """
    self.daemon._in_queue.put(
        _FunctionCall(name=function_name, kwargs=kwargs, asynchronous=False)
    )
    return self.daemon._sync_out_queue.get()

    def stop_thread(self) -> None:
    """Stop background QThread."""
    if self._listener.isRunning():
        # None is used as a sentinel value to signal that the thread should stop
        self.daemon._async_out_queue.put(None)
        self._listener.wait()
